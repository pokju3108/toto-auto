⚽ RUN TOTO 개인정보처리방침

최종 업데이트: 2026년 4월

RUN TOTO 승무패 분석 앱(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 개인정보 보호법 및 관련 법령을 준수합니다.

1. 수집하는 정보

본 앱은 다음과 같은 정보를 수집하지 않습니다:

  • 개인 식별 정보 (이름, 이메일, 전화번호 등)
  • 위치 정보
  • 결제 정보
  • 연락처, 사진 등 기기 내 개인 데이터

앱은 사용자가 직접 입력한 베팅 조합 선택 정보를 기기 내 로컬 저장소(localStorage)에만 저장하며, 외부 서버로 전송하지 않습니다.

2. 정보 이용 목적

앱은 축구토토 승무패 조합 계산 및 분석 기능을 제공하기 위해 다음을 활용합니다:

  • 공개된 투표율 데이터 (구글 시트 공개 API)
  • 사용자가 직접 선택한 경기 예측 조합 (기기 내 저장)

3. 제3자 서비스

본 앱은 다음 제3자 서비스를 사용합니다:

  • Google Sheets API: 투표율 데이터 조회 (읽기 전용, 공개 데이터)
  • Netlify: 앱 호스팅 서비스

각 서비스의 개인정보처리방침은 해당 서비스 제공자의 정책을 따릅니다.

4. 데이터 보안

앱은 사용자 데이터를 외부 서버에 저장하거나 전송하지 않습니다. 모든 사용자 설정은 기기 내 로컬 저장소에만 보관됩니다.

5. 아동 개인정보 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 개인정보처리방침 변경

본 방침은 변경될 수 있으며, 변경 시 앱 내 공지 또는 본 페이지를 통해 안내드립니다.
